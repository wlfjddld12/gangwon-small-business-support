# 강원 소상공인 혜택 도우미

강원특별자치도 소상공인이 자신의 사업 상황에 맞는 지원사업을 보다 쉽게 찾을 수 있도록 만든 AI 기반 정책지원 추천 웹서비스입니다.

복잡한 지원사업 공고를 사용자가 직접 하나씩 찾아보지 않아도, 필요한 지원 유형과 현재 사업 상황을 입력하면 관련성이 높은 지원사업을 찾아 최대 3개까지 추천합니다.

## 프로젝트 배경

소상공인을 위한 정책자금, 보증, 고용지원, 마케팅 등 다양한 지원사업이 운영되고 있지만 사업별 지원 대상과 조건이 달라 자신에게 필요한 제도를 직접 찾기 어렵다는 문제가 있습니다.

특히 이 프로젝트는 강원특별자치도 지역의 소상공인을 주요 대상으로 설정하고, 지역에서 이용할 수 있는 지원사업 정보를 보다 쉽게 탐색할 수 있도록 하는 것을 목표로 개발했습니다.

## 주요 기능

### 1. 필요한 지원 분야 선택
사용자가 현재 필요한 지원 분야를 선택할 수 있습니다.

- 지원금
- 대출·융자
- 보증
- 기술개발
- 전체

### 2. 자연어 기반 사업 상황 입력
지역, 업종, 매출 상황, 경영상의 어려움 등을 사용자가 평소 말하듯 입력할 수 있습니다.

예시:

> 원주에서 작은 식당을 운영하고 있는데 요즘 매출이 줄어 지원을 받고 싶어요.

### 3. 추가 질문을 통한 추천 보완
초기 입력만으로 정확한 판단이 어려운 경우 사용자가 현재 가장 필요로 하는 지원을 추가로 선택할 수 있도록 구성했습니다.

### 4. 맞춤형 지원사업 추천
입력한 사업 상황을 바탕으로 관련성이 높은 지원사업을 최대 3개까지 추천합니다.

추천 결과에서는 다음 정보를 확인할 수 있습니다.

- 지원 한도
- 지원사업명
- 지원 유형
- 추천 이유
- 지원 대상
- 문의처
- 근거자료

## 기술 구성

- Python
- Streamlit
- Google Gemini API
- ChromaDB
- Sentence Transformers
- PyPDF
- Git / GitHub

## 서비스 구조

```text
지원 분야 선택
      ↓
사업 상황 자연어 입력
      ↓
사용자 요구 분석
      ↓
추가 조건 확인
      ↓
정책지원 데이터 검색
      ↓
관련성 분석 및 추천
      ↓
최대 3개 지원사업 제시
```

## 프로젝트의 특징

### 강원특별자치도 중심의 지역 특화 서비스
전국 단위의 범용 정책검색 서비스와 달리 강원특별자치도 소상공인의 지원사업 탐색에 초점을 맞췄습니다.

### 복잡한 정책명을 몰라도 검색 가능
사용자가 정확한 사업명을 알고 있지 않아도 자신의 상황을 자연어로 설명하여 관련 지원사업을 탐색할 수 있도록 설계했습니다.

### 추천 근거 제공
지원사업 이름만 제시하는 것이 아니라 추천 이유, 지원 대상, 문의처와 근거자료를 함께 제공하도록 구성했습니다.

## 이용 시 유의사항

본 서비스의 추천 결과는 지원사업 탐색을 돕기 위한 참고 정보입니다.

실제 지원 가능 여부, 신청 기간, 세부 요건 및 지원 내용은 변경될 수 있으므로 신청 전 반드시 담당기관의 최신 공고를 확인해야 합니다.

## 향후 개선 방향

- 지원사업 데이터 정기 업데이트
- 시·군별 지역 필터 고도화
- 업종 및 사업자 특성별 추천 정확도 향상
- 지원사업 신청 페이지 연결
- 모바일 환경 UI 개선
- 추천 결과의 근거 및 출처 표시 강화
